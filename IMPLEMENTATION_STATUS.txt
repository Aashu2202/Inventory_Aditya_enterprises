## 🔌 API Endpoints Available

### Companies
- `GET /api/companies` - Get all companies
- `GET /api/companies/:id` - Get company by ID
- `POST /api/companies` - Create company
- `PUT /api/companies/:id` - Update company
- `DELETE /api/companies/:id` - Soft delete company
- `POST /api/companies/:id/logo` - Upload logo

### Bills
- `GET /api/bills` - Get all bills (filtered by company)
- `GET /api/bills/:id` - Get bill details
- `POST /api/bills` - Create bill
- `PUT /api/bills/:id` - Update bill
- `POST /api/bills/:id/items` - Add items
- `DELETE /api/bills/:billId/items/:itemId` - Remove item
- `POST /api/bills/:id/finalize` - Finalize bill
- `POST /api/bills/:id/cancel` - Cancel bill
